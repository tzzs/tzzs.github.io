## v0.1.0

初始版本，实现完整功能集：

- CPU / 内存 / 磁盘 / 网络 / GPU / Docker 采集，直读 `/proc` 与本地系统调用，零常态子进程开销
- 状态栏默认仅展示 1 个核心指标，视觉语言对齐原生延迟指示器，越阈值才变色
- Tooltip 内置迷你趋势图，点击弹出 Webview 折线图
- 窗口焦点感知的双通道自适应轮询（轻量 `/proc` 指标 vs 重量级 GPU/Docker 指标）
- 非 Linux 远程主机优雅降级（CPU/内存回退到 `os` 模块，网络模块直接隐藏）
- 关键指标解析函数均有单元测试覆盖
