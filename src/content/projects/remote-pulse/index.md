Remote Pulse 是一个 VS Code 扩展，持续追踪 **Remote-SSH 远程主机的 CPU / 内存 / 磁盘 / 网络 / GPU / Docker** 状态，像 VS Code 原生的延迟指示器一样安静，不打断编码心流。

## 为什么需要它

多数同类扩展的做法是把一整个监控面板搬进状态栏：信息密集，且常驻占用视觉空间。Remote Pulse 走了不同的路线：

| 维度 | 常见做法 | Remote Pulse |
| --- | --- | --- |
| 常驻占用 | CPU/内存/磁盘一次性平铺展示 | 默认只显示 1 个图标 + 1 个核心数字，其余都收进趋势面板 |
| 配色逻辑 | 始终按数值着色 | CPU 与内存各自独立按绿/黄/红分级，与 VS Code 原生远程连接指示器视觉语言一致 |
| 交互方式 | 部分需要打开侧边栏 | 点击弹出轻量 Webview，不占用常驻空间，关闭后不留痕迹 |
| 资源开销 | 部分靠拉起子进程轮询 | 直接读取 `/proc`，核心指标零常态子进程开销 |
| 场景感知 | 无论是否聚焦都同频轮询 | 窗口失焦自动降频 |

## 功能特性

- **CPU**：整体使用率与核心数（基于 `/proc/stat` 增量计算，而非 loadavg）
- **内存**：使用率与已用/总量（采用 `MemAvailable` 而非 `MemFree`，更贴近实际可用量）
- **磁盘**：按挂载点展示使用率，自动过滤虚拟文件系统，并合并同一磁盘的重复挂载点（如 WSL2 场景）
- **网络**：下载/上传速率始终分开展示，而非合并成一个数字
- **GPU**：显存占用、利用率、温度（依赖 `nvidia-smi`，不可用时模块自动保持不活跃）
- **Docker**：运行中容器数与逐容器 CPU/内存占用（依赖 `/var/run/docker.sock` 访问权限，无权限时静默降级）
- **阈值告警**：CPU/内存越过警告/严重阈值时独立变色，可选系统通知（进入严重状态时仅提示一次）
- **历史趋势**：点击状态栏项或运行命令，弹出最近 30 分钟的折线图
- **自适应轮询**：窗口失焦后自动降低刷新频率，减轻远程主机负载
- **本地化界面**：命令、设置与状态栏/面板文案跟随 VS Code 显示语言（默认英文，附简体中文翻译）

## 适用场景

通过 Remote-SSH 连接 Linux 远程主机进行开发时，无需额外配置即可在状态栏看到远程主机的实时负载（扩展声明了 `extensionKind: workspace`，会自动运行在远程扩展主机上）。非 Linux 远程主机会优雅降级：CPU/内存回退到 Node.js `os` 模块，网络模块直接隐藏。
