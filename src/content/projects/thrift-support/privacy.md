---
title: Thrift Support 隐私政策
pubDate: 2026-08-05
order: 3
---

**Thrift Support 不收集、不存储、不传输任何个人数据。**

本扩展的所有分析均在本地完成：

- 解析与格式化只在本机 VS Code 进程中执行
- 不向任何服务器发送代码内容或使用数据
- 不包含遥测、统计上报或第三方跟踪
- CLI 模式（thrift-lint / thrift-format 等）同样完全本地运行

## 数据说明

| 数据类型 | 是否收集 |
| --- | --- |
| IDL 代码内容 | 否（仅在本地进程内分析） |
| 个人身份信息 | 否 |
| 使用统计 | 否 |

## 联系方式

如有隐私相关问题，请通过 [GitHub Issues](https://github.com/tzzs/vsce-thrift-support/issues) 反馈。
