**生效日期：2026 年 8 月 3 日**

**发行者：tanzz**

外设助手（PeriPilot，以下简称"本应用"）是一款在 Windows 设备本机运行的外设电量与充电提醒工具。本政策说明本应用如何处理信息。

## 一、处理的信息

本应用通过 Windows HID 接口访问明确支持的外设及其 2.4G 接收器，以读取和处理以下信息：

1. 设备型号和应用内部设备标识；
2. 设备的连接、在线、休眠或不可用状态；
3. 电量百分比和充电状态；
4. 对于支持该能力的设备，读取电池电压；
5. 状态读取时间和必要的本地错误状态。

这些信息仅用于在本机显示设备状态、保留最近一次有效读数，以及触发用户配置的低电量或充满电提醒。本应用可能在运行期间临时访问 HID 设备路径以与设备通信，但不会将完整设备路径或设备序列号保存到应用数据中。

## 二、本地保存的数据

本应用会在当前 Windows 用户的 `%LocalAppData%\PeriPilot` 目录中保存以下数据：

1. 用户设置，包括主题、应用图标、轮询间隔和提醒配置；
2. 已触发提醒的本地去重状态；
3. 最近一次有效的设备状态快照，包括设备名称、连接状态、电量、充电状态、可用电压和读取时间；
4. 应用运行所需的本地图标缓存。

上述数据仅保存在用户设备上，用于提供本应用功能。

## 三、网络传输和数据共享

当前版本不创建用户账户，不包含广告、分析、遥测或云同步功能，也不会向发行者或第三方服务器上传设备数据、用户设置或使用记录。

本应用不出售、出租或以其他方式向第三方提供个人数据。

## 四、系统权限

本应用使用 Windows 桌面应用权限访问本机 HID 设备、显示系统通知、提供通知区域图标，并读写上述本地应用数据。本应用不会修改外设固件、EEPROM、DPI、按键映射、灯效或其他设备配置。

## 五、数据保留与删除

本地数据会保留至用户删除它们。用户可以退出本应用后，删除 `%LocalAppData%\PeriPilot` 文件夹，以清除本应用保存的全部本地数据。

卸载 Microsoft Store 版本后，如果该目录仍然存在，用户也可以按上述方式手动删除。删除本地数据不会影响外设本身的设置或固件。

## 六、儿童隐私

本应用不要求用户提供姓名、年龄、联系方式或账户信息，也不会主动收集儿童的个人数据。

## 七、政策变更

如果本应用的功能或数据处理方式发生变化，本政策将相应更新，并修改生效日期。重大变化会通过 Microsoft Store 商品页面、应用更新说明或其他适当方式告知用户。
