# LUT Studio

面向视频创作者的 LUT 调色工具。

## 产品介绍

LUT Studio 是一款专注于 LUT（查找表）调色的桌面工具，服务对象是短视频、纪录片与独立电影的创作者。它以「所见即所得」为核心——实时预览、即时导出，把调色从繁琐的参数堆叠中解放出来，让你把时间花在创作上而不是流程上。

无论是为整条片子统一风格，还是为某个镜头快速校正色彩，LUT Studio 都能在一个轻量、专注的界面里完成。

## 核心功能

- **实时预览**：加载素材即见效果，LUT 强度可无级调节，支持 A/B 对比
- **3D LUT 导出**：一键导出 .cube 格式，兼容 DaVinci Resolve、Premiere Pro、Final Cut Pro 等主流软件
- **批量套用**：对整批素材批量套用并统一输出，适合项目级风格统一
- **色彩示波器**：内置波形图、矢量示波器，辅助判断曝光与色偏
- **内置风格库**：附赠 20+ 基础电影感预设，可自定义收藏

## 使用场景

- **短剧与 vlog 风格统一**：拍摄多条素材后批量套用同一风格，保证成片色调一致
- **纪录片还原校正**：针对不同机位素材做白平衡与色彩还原
- **直播与快速交付**：为多机位直播输出统一的 LUT，开播前几分钟即可完成配置
