# Markdown Editor

极简、专注的跨平台 Markdown 编辑器。

## 产品介绍

Markdown Editor 是一款把「专注写作」做到极致的 Markdown 编辑器。没有侧边栏堆砌、没有弹窗引导、没有账号系统——打开即写，关闭即走。它适合所有用 Markdown 写作的人：博主、工程师、学生，以及一切厌恶编辑器干扰的人。

我们相信写作工具应该隐身。界面只保留必要元素，快捷键覆盖高频操作，支持无干扰模式，让你在纯文本的安静里完成表达。

## 核心功能

- **实时预览**：编辑区与预览区并排，可随时切换纯编辑模式
- **本地文件优先**：直接打开本地目录与文件，无需导入导出流程
- **一键导出**：导出为 PDF、HTML，或复制为富文本粘贴到博客后台
- **无干扰模式**：一键隐藏所有面板，只留光标与文字
- **快捷键体系**：标题、引用、代码块等高频操作均可键盘完成

## 使用场景

- **写博客草稿**：本地写好 Markdown 草稿，一键导出粘贴到 Hexo / Astro 等博客
- **会议与课堂记录**：纯文本记录，结构清晰，事后可快速转成正式文档
- **技术文档写作**：原生支持代码块与目录大纲，写 README、接口文档顺手自然
