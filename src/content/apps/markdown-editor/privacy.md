# 隐私政策

最后更新：2026-07-28

Markdown Editor 是一款本地优先的写作工具。你的文档是你的，我们默认不触碰。

## 我们收集哪些数据

- **文档内容**：默认完全保存在本地；Web 版在浏览器内处理，不上传文档内容
- **本地偏好设置**：如主题、编辑器布局等，仅保存在你的设备上
- **使用数据**：匿名化崩溃日志（用于稳定性修复，可随时关闭）
- **不收集**：我们不需要注册账号，也不收集你的文档、复制内容或输入历史

## 数据用途

- 文档内容仅用于在本地呈现与编辑
- 崩溃日志仅用于修复稳定性问题

## 数据存储与删除

- 本地文件由你管理，删除文件即彻底删除
- 我们不维护任何云端文档副本
