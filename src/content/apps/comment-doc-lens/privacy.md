**Comment Doc Lens 不收集、不存储、不传输任何个人数据。**

本扩展的所有分析均在本地完成：

- 扫描的代码、符号与文档注释只在本机 VS Code 进程中处理
- 不向任何服务器发送代码内容或使用数据
- 不包含遥测、统计上报或第三方跟踪
- 不修改你的源文件（只读分析并渲染 inlay hint）

## 数据说明

| 数据类型 | 是否收集 |
| --- | --- |
| 代码内容 | 否（仅在本地进程内分析） |
| 个人身份信息 | 否 |
| 使用统计 | 否 |
| 诊断数据 | 否（仅在需要反馈时由用户手动复制） |

## 联系方式

如有隐私相关问题，请通过 [GitHub Issues](https://github.com/tzzs/comment-doc-lens/issues) 反馈。
